# 3. Daily Workflows

One page per transaction *story* — end-to-end, the way an actual bookkeeper
would describe what they did today. Not "fields on a form" — "what happens
when a customer pays half up front, picks up two items, backorders one, and
returns one a week later."

Each workflow names the journals used, the GL postings produced, and the
common variations / gotchas.
