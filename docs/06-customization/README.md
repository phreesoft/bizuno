# 6. Customization & Extensions

How to bend Bizuno to a specific business *without forking the core repo*.
The `myExt/` pattern, override functions, plug-in journals, custom payment
gateways, custom PhreeForm processors.

This is where Bizuno earns its keep against off-the-shelf accounting apps:
clients with unusual workflows get a clean extension surface instead of "you
can't do that in QuickBooks."
