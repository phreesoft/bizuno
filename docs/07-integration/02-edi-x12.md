# EDI X12

> **Status:** Stub — not yet drafted.

## What this page will cover

- Bizuno's EDI implementation: X12 standard, current supported transactions (850 PO inbound, 810 invoice outbound, 855 PO ack, 856 ASN, 997 functional ack)
- Configuring a trading partner (sender/receiver IDs, control numbers, file naming conventions)
- Inbound 850 lifecycle: file drops → parse → map to SO → post → emit 997
- Outbound 810 lifecycle: trigger on invoice post → build segments → write to outbound dir → 997 expected back
- Segment-level reference: ISA/GS/ST envelope, BIG/BEG, N1/N3/N4 addresses, PO1/PID line items, CTT/SE/GE/IEA footer
- Handling unrecognized segments (the N9 + MSG pattern: capture as a $0 description line on the SO; see 7.3.9 release notes)
- Error responses (997 with errors) and reconciliation
- Reading the EDI trace file

## Why it matters

EDI is dense and infrequent; users hit it once a quarter and have forgotten
everything. Doc has to be reference-grade, not tutorial-grade.
