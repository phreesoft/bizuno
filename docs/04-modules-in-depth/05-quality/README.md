# 4.5 Quality

ISO-9001-style quality management. Corrective/Preventive Action tickets,
audits, training records, scheduled maintenance, quality objectives.

The Quality module is one of Bizuno's biggest differentiators against typical
small-business accounting apps — most don't ship anything resembling this
out of the box.
