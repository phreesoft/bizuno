# 4.3 Inventory

Stock items, costing methods, assemblies (kitted SKUs), and production work
orders. The interaction with PhreeBooks happens through
[inventory types](../../02-core-concepts/05-inventory-types-and-cogs.md) —
some types post COGS, some don't, and the choice is permanent once you
transact.
