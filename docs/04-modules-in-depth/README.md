# 4. Modules in Depth

The reference section. Each module gets its own subdirectory; each
sub-feature its own page. Where the [Daily Workflows](../03-daily-workflows/)
section answers *"how do I do X"*, this section answers *"what does this
screen / setting / sub-feature actually do"*.

## Modules

| Module                                         | Purpose                                                     |
|------------------------------------------------|-------------------------------------------------------------|
| [PhreeBooks](./01-phreebooks/)                 | Double-entry GL. The accounting core. Largest module.       |
| [PhreeForm](./02-phreeform/)                   | Report + form engine. Custom invoices, statements, reports. |
| [Inventory](./03-inventory/)                   | Stock, costing, assemblies, production work orders.         |
| [Contacts](./04-contacts/)                     | Customers, vendors, employees, projects (one table).        |
| [Quality](./05-quality/)                       | ISO-9001-style CA/PA tickets, audits, training, maintenance.|
| [Shipping](./06-shipping/)                     | Carrier integrations, label printing, Zebra Browser Print.  |
