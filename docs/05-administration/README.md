# 5. Administration

How to operate a Bizuno install: users, roles, security, backups, fiscal-year
close, cache management, and the hook system that lets you override core
behavior without forking.

Audience for this section is *admin* — the person who installed Bizuno and
keeps it running. End-user bookkeepers don't need to read this; developers
should still know it exists.
